# DigitalPlat FreeDomain

Free domain registration and practical DNS learning resources for everyone.
(为所有人提供免费域名注册与实用的 DNS 学习资源。)

注册一个域名,通过自定义 Nameserver 接入你偏好的 DNS 服务商,再借助随附的学习指南,把一个项目从"注册"一路推进到"上线部署"。

➡️ [注册域名(Dashboard)](https://dash.domain.digitalplat.org/) · 📖 [阅读教程](https://github.com/DigitalPlatDev/FreeDomain/blob/main/documents/tutorial/index.md) · 📚 [浏览学习指南(LEARN.md)](https://github.com/DigitalPlatDev/FreeDomain/blob/main/LEARN.md) · 💻 [查看应用源码(Domain-OSS)](https://github.com/DigitalPlatDev/Domain-OSS)

> 说明:本仓库存放 DigitalPlat FreeDomain 的公开信息与学习资源;域名申请面板的应用源代码单独维护于 [DigitalPlatDev/Domain-OSS](https://github.com/DigitalPlatDev/Domain-OSS)。

## ✔️ 为什么要提供免费域名?

在 **DigitalPlat FreeDomain**,我们的使命是让互联网的门槛更低。我们相信,域名的费用不应该成为任何人创建网站的阻碍。我们的目标是让互联网成为一个开放的空间——无论预算多少,每个人都能在网上拥有属于自己的一席之地。

> DigitalPlat FreeDomain 由 DigitalPlat 基金会创始人 [**Edward Hsing**](https://github.com/EdwardLab) 独立设计与维护。
