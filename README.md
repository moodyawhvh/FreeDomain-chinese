## 📖 项目简介

DigitalPlat FreeDomain 是一项面向所有人的免费域名注册服务,同时提供成体系的 DNS 实战学习资源。注册一个免费域名后,通过自定义 NS 记录接入你喜欢的任意 DNS 服务商,再配合官方学习指南,就能把一个项目从"注册域名"一路走到"上线部署"。目前已有超过 50 万个域名在这里注册,由 DigitalPlat 基金会创始人 Edward Hsing 独立设计与维护。

## ✨ 主要特性

- **完全免费**:注册 .DPDNS.ORG、.US.KG、.QZZ.IO、.XX.KG、.QD.JE 等多种免费二级域名,后续还会新增更多后缀
- **自定义 NS 解析**:域名注册后可自由接入 Cloudflare、DNSPod 等任意 DNS 服务商
- **成体系的学习指南**:提供书式学习路径(LEARN.md),从域名 setup 到 DNS、网站、邮箱、运维与进阶主题
- **新手友好教程**:附完整的注册与使用教程,零基础也能完成从注册到部署的全流程
- **社区活跃**:官方 Discord 社区 + GitHub Discussions,问题反馈与交流畅通
- **开源应用**:域名申请面板(DigitalPlat Domain)本身开源,可自行查阅与部署
- **滥用治理**:设有专门的滥用举报渠道,认真处理每一份举报,维护更安全的互联网环境
- **公益初衷**:让"没有预算"不再是拥有自己网站的门槛

## 🚀 快速开始

1. 打开 [DigitalPlat FreeDomain 官方注册面板](https://dash.domain.digitalplat.org/),注册/登录账号
2. 在面板中搜索并选择心仪的免费域名后缀(如 `.DPDNS.ORG`、`.US.KG`),提交申请
3. 等待申请审核通过,域名即可归你使用
4. 在域名管理中设置自定义 Nameserver,接入你惯用的 DNS 服务商
5. 跟随 [官方教程](https://github.com/DigitalPlatDev/FreeDomain/blob/main/documents/tutorial/index.md) 完成解析配置
6. 参考 [LEARN.md 学习指南](https://github.com/DigitalPlatDev/FreeDomain/blob/main/LEARN.md),从 DNS 基础一路学到网站、邮箱与运维部署
7. 遇到问题可查阅 [FAQ](https://github.com/DigitalPlatDev/FreeDomain/blob/main/documents/domains/faq.md),或加入官方 Discord / GitHub Discussions 提问
